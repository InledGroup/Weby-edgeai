# Instrucciones de Instalación - Weby

Para cargar la extensión en tu navegador Chrome o basado en Chromium:

1. **Descarga y descomprime** el archivo `.zip` de la última release.
2. Abre tu navegador y ve a `chrome://extensions`.
3. Activa el **Modo de desarrollador** (interruptor en la esquina superior derecha).
4. Haz clic en el botón **Cargar descomprimida** (Load unpacked).
5. Selecciona la carpeta que acabas de descomprimir (la que contiene el archivo `manifest.json`).
6. ¡Listo! Ya puedes empezar a usar Weby desde el panel lateral.

---
**Nota:** Al ser una carga en modo desarrollador, es posible que el navegador te avise al iniciar que estás usando extensiones en pruebas. Simplemente ignora el aviso.
